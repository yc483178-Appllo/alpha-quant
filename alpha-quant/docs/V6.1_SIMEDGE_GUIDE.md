## 数据库变更

### 新增表结构

#### sim_accounts (模拟账户表)
```sql
CREATE TABLE sim_accounts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_name VARCHAR(50) NOT NULL,
    initial_capital DECIMAL(15,2) NOT NULL,
    available_cash DECIMAL(15,2) NOT NULL,
    total_value DECIMAL(15,2) NOT NULL,
    total_profit DECIMAL(15,2) DEFAULT 0,
    total_return_pct DECIMAL(10,4) DEFAULT 0,
    max_drawdown DECIMAL(10,4) DEFAULT 0,
    sharpe_ratio DECIMAL(10,4) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status VARCHAR(20) DEFAULT 'active'
);
```

#### sim_positions (模拟持仓表)
```sql
CREATE TABLE sim_positions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id INTEGER NOT NULL,
    stock_code VARCHAR(20) NOT NULL,
    stock_name VARCHAR(50),
    quantity INTEGER NOT NULL,
    avg_cost DECIMAL(10,4) NOT NULL,
    current_price DECIMAL(10,4),
    market_value DECIMAL(15,2),
    unrealized_pnl DECIMAL(15,2),
    unrealized_pnl_pct DECIMAL(10,4),
    sector VARCHAR(50),
    opened_at TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### sim_orders (模拟订单表)
```sql
CREATE TABLE sim_orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id INTEGER NOT NULL,
    order_id VARCHAR(50) UNIQUE NOT NULL,
    stock_code VARCHAR(20) NOT NULL,
    order_type VARCHAR(20) NOT NULL,  -- MARKET, LIMIT
    action VARCHAR(10) NOT NULL,       -- BUY, SELL
    quantity INTEGER NOT NULL,
    price DECIMAL(10,4),
    filled_quantity INTEGER DEFAULT 0,
    filled_price DECIMAL(10,4),
    status VARCHAR(20) DEFAULT 'pending',  -- pending, partial, filled, cancelled, rejected
    strategy VARCHAR(50),
    signal_id INTEGER,
    commission DECIMAL(10,4) DEFAULT 0,
    slippage DECIMAL(10,4) DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    filled_at TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### sim_transactions (模拟成交表)
```sql
CREATE TABLE sim_transactions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id INTEGER NOT NULL,
    order_id VARCHAR(50) NOT NULL,
    transaction_id VARCHAR(50) UNIQUE NOT NULL,
    stock_code VARCHAR(20) NOT NULL,
    action VARCHAR(10) NOT NULL,
    quantity INTEGER NOT NULL,
    price DECIMAL(10,4) NOT NULL,
    amount DECIMAL(15,2) NOT NULL,
    commission DECIMAL(10,4) NOT NULL,
    stamp_tax DECIMAL(10,4) DEFAULT 0,  -- 印花税
    transfer_fee DECIMAL(10,4) DEFAULT 0,  -- 过户费
    total_cost DECIMAL(15,2) NOT NULL,
    realized_pnl DECIMAL(15,2),
    transaction_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### sim_fund_flow (资金流水表)
```sql
CREATE TABLE sim_fund_flow (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    account_id INTEGER NOT NULL,
    flow_type VARCHAR(30) NOT NULL,  -- initial_capital, buy_order, sell_order, commission, tax
    amount DECIMAL(15,2) NOT NULL,
    balance_after DECIMAL(15,2) NOT NULL,
    reference_id VARCHAR(50),  -- 关联的order_id或transaction_id
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## API 接口文档

### 模拟盘 API 端点

#### 账户管理
```
GET    /v3/api/simulation/account           # 获取模拟账户信息
POST   /v3/api/simulation/account/create    # 创建模拟账户
POST   /v3/api/simulation/account/reset     # 重置模拟账户
PUT    /v3/api/simulation/account           # 更新账户配置
```

#### 持仓查询
```
GET    /v3/api/simulation/positions         # 获取模拟持仓列表
GET    /v3/api/simulation/positions/<code>  # 获取指定股票持仓
```

#### 订单操作
```
POST   /v3/api/simulation/orders            # 提交模拟订单
GET    /v3/api/simulation/orders            # 查询订单列表
GET    /v3/api/simulation/orders/<id>       # 查询订单详情
DELETE /v3/api/simulation/orders/<id>       # 撤单
```

#### 成交查询
```
GET    /v3/api/simulation/transactions      # 查询成交记录
GET    /v3/api/simulation/transactions/<id> # 查询成交详情
```

#### 资金流水
```
GET    /v3/api/simulation/fundflow          # 查询资金流水
```

#### 业绩报告
```
GET    /v3/api/simulation/performance       # 获取业绩指标
GET    /v3/api/simulation/equity_curve      # 获取权益曲线
```

## 部署步骤

### 1. 备份现有系统
```bash
cd /root/.openclaw/workspace/alpha-quant
mkdir -p backups/v6.0_$(date +%Y%m%d)
cp -r * backups/v6.0_$(date +%Y%m%d)/
```

### 2. 数据库迁移
```bash
# SQLite
sqlite3 data/simulation.db < migrations/v6.1_simulation_schema.sql
```

### 3. 配置文件更新
```bash
# 备份原配置
cp config.json config.json.bak
# 新版本配置已包含模拟盘配置段
```

### 4. 启动服务
```bash
# 重启看板服务
python dashboard_data_bridge.py

# 或者使用生产模式
supervisorctl restart alpha-dashboard
```

## 回滚方案

如需回滚到V6.0:
```bash
cd /root/.openclaw/workspace/alpha-quant
# 恢复配置文件
mv config.json config.json.v6.1
mv config.json.bak config.json
# 停止服务后重新启动V6.0版本
```

## 注意事项

1. **数据隔离**: 模拟盘数据存储在独立数据库，不影响实盘数据
2. **资金初始化**: 默认模拟账户初始资金为100万
3. **交易规则**: 模拟盘遵循A股T+1规则
4. **费用模拟**: 包含佣金、印花税、过户费等真实费用模拟
